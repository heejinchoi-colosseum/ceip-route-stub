사용자 입력
서비스 보유 값 (사용자 입력 없음 · 함께 전송)

start 는 service=colo1.0 으로 분기해 이 호스트(CALLBACK_HOST_COLO1)를 redirect_uri 로 고르고, 실어 나를 값을 조합한다.

Cafe24 쇼핑몰 ID. 동의 화면이 https://{mallId}.cafe24api.com 에 뜬다. 기본값은 CAFE24_MALL_ID 이고, 테스트 중에는 바꿔 넣을 수 있다. URL 이 아니라 ID 만 넣는다(예: coloceip).

콜백이 토큰 교환 뒤 302 할 곳. 상대 경로라 콜백 호스트(이 호스트)의 /cafe24/demo/return 으로 온다.

AUTHORIZE 를 누르면 {{startUrl}} 로 GET 한다. sellerId, warehouseId 는 redirect_uri 가 아니라 서명 state 에 실려 콜백으로 돌아오고, /cafe24/demo/return 쿼리에 그대로 붙는다. Cafe24 는 콜백에 hmac 이 없어 이 서명 state 로만 검증한다. Cafe24 는 라우터 콜백(8080)으로 code 를 보내고, 라우터가 state 의 service 로 이 호스트 콜백에 넘긴다.
